# Deployment Skill

This skill handles project deployment to GitHub and domain configuration for web applications.

## Features
- GitHub repository creation and setup
- Domain configuration and DNS setup
- Deployment configuration for full-stack applications
- Environment variable management
- Production deployment best practices

## Usage
Invoke this skill when:
- User wants to deploy a project to GitHub
- User needs domain configuration
- User wants to setup hosting for web applications
- User needs deployment scripts and configuration

## Supported Platforms
- GitHub Pages
- Vercel
- Netlify
- Custom domain setup
- SSL certificate configuration
